공대몬 포토부스 설치 안내 (업체 부스 PC용)
==========================================

[필요한 것]
- 윈도우 PC 1대, 구글 크롬 설치
- 웹캠 (USB 연결)
- 포토 프린터 (윈도우에 드라이버 설치, "기본 프린터"로 지정)
- 인터넷: 없어도 됨 (QR 기능만 인터넷 필요)


[1] 설치
1. 이 폴더(gongdaemon-photobooth)를 통째로 C:\ 바로 아래에 복사
   → C:\gongdaemon-photobooth\index.html 이 되도록
   (경로에 한글이나 띄어쓰기가 없으면 가장 안전해요)
2. 폴더 안의 파일을 따로 옮기거나 지우지 마세요. mp, lib 폴더도 필요해요.


[2] 프린터 준비 (가장 중요)
1. 윈도우 설정 → 블루투스 및 장치 → 프린터 및 스캐너
   → "Windows에서 기본 프린터 관리" 끄기
   → 포토 프린터 선택 → "기본값으로 설정"
2. 같은 화면에서 프린터 기본 설정(인쇄 기본 설정)을 열고
   - 용지 크기: 실제로 넣은 용지 (예: 4x6 / 102x152mm)
   - 테두리 없음(Borderless) 켜기
   - 방향: 가로 (카드 2장 배치 기준)


[3] 처음 한 번: 설정 + 테스트 인쇄
1. TEST_window_mode.bat 실행 (일반 창으로 열림)
2. 카메라 권한을 "허용"
3. 시작 화면 왼쪽 아래 "⚙️ 설정"에서
   - 카메라: 부스 웹캠 선택
   - 인쇄 용지 / 배치 선택
4. "테스트 인쇄" 버튼 → 인쇄창이 뜨면 대상 프린터 확인 후 인쇄
5. 나온 종이에서 확인
   - 카드 한 장이 가로 63mm, 세로 88mm 인가요?
   - 위쪽 빨간 눈금자가 정확히 50mm 인가요?
   → 다르면 설정의 "보정: 크기(%)"를 조절
     (예: 눈금자가 48mm로 나오면 50÷48×100 = 104%)
   → 한쪽으로 쏠리면 "보정: 좌우/상하(mm)" 조절
6. "저장하고 닫기" → 크롬 창 닫기


[4] 행사 당일 실행
1. START_photobooth.bat 더블클릭
   → 전체화면(키오스크)으로 켜지고, 카드가 완성되면
     인쇄창 없이 기본 프린터로 바로 출력돼요.
2. 설정 열기: Ctrl + Shift + S
   (키보드가 없으면 왼쪽 위 타이머 자리를 빠르게 5번 터치)
3. 종료: Alt + F4
※ 실행 전에 다른 크롬 창이 열려 있어도 괜찮아요.
   이 프로그램은 별도 크롬 프로필(chrome-profile 폴더)로 켜져요.


[인쇄 동작]
- 카드 수 = 연구 인원 수 (설정에서 고정 매수로 바꿀 수 있음)
- 4x6 용지 한 장에 카드 2장, 남는 1장은 가운데 배치
- 카드 둘레에 재단선이 있어요 → 재단기로 자르고 모서리 라운딩
- "다시 인쇄"는 기본 1회까지 허용 (설정에서 변경)
- 완성 카드 PNG는 다운로드 폴더에도 자동 저장 (백업용)


[문제가 생기면]
- 인쇄창이 계속 뜸 → START_photobooth.bat 으로 켰는지 확인
  (다른 크롬이 같은 프로필로 이미 켜져 있으면 옵션이 안 먹어요. 작업관리자에서 크롬 모두 종료 후 다시 실행)
- 엉뚱한 프린터로 나감 → [2]의 기본 프린터 지정 다시 확인
- 카드가 작게/크게 나옴 → [3]-5 보정
- 카메라 화면이 안 나옴 → 웹캠 USB 다시 연결 후 재실행, 설정에서 카메라 다시 선택
- 시작 화면 아래에 "배경 지우기 불러오기 실패" → mp 폴더가 같이 있는지 확인 (없어도 원본 사진으로 진행은 돼요)


[QR 설정] (인터넷 필요)
1. https://api.imgbb.com 접속 → 회원가입/로그인 → "Get API key" 로 키 발급 (무료)
2. 둘 중 하나로 키 넣기
   - config.js 를 메모장으로 열고 imgbbKey: '' 따옴표 안에 키 붙여넣고 저장
   - 또는 프로그램 설정(Ctrl+Shift+S) → imgbb API 키 칸에 붙여넣기
3. 설정의 "QR 연결 테스트" → "연결 성공"이 뜨면 끝
4. QR 만들기 방식
   - 학우가 버튼 누를 때(기본): 완성 화면의 "QR로 폰에 받기"를 누른 사람만 업로드
   - 완성 즉시 자동 / 쓰지 않음 중 선택 가능
※ 사진은 imgbb에 30일 보관 후 자동 삭제. 링크를 아는 사람만 볼 수 있음
※ 인터넷이 끊겨도 촬영·인쇄는 그대로 됨 (QR만 안 됨)
